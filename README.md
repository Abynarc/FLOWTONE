# FLOWTONE

Определение BPM и тональности, сдвиг высоты звука без изменения темпа. AU для macOS и VST3 для Windows.

Интерфейс **Русский / English**: переключатель **RU / EN** справа от «Обход». Язык сохраняется в проекте.

![FLOWTONE](docs/images/flowtone.png)

- Анализ всего файла или входа дорожки при воспроизведении.
- Сдвиг от −12 до +12 полутонов с шагом 50 центов.
- Сохранение формант, два режима качества и выходная громкость.
- A/B, пресеты и сравнение «До / После».
