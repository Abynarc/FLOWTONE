# FLOWTONE for Windows

Close your DAW and run `FLOWTONE-0.4.0-Windows-x64-Setup.exe`. The installer supports English and Russian. Rescan plug-ins in your DAW. In FL Studio, open Manage plugins → Find installed plugins. The VST3 is installed to `C:\Program Files\Common Files\VST3\FLOWTONE.vst3`.

Select **EN** in the language dropdown beside Bypass. Select **RU** to return to Russian. The choice is saved with the project and does not change audio settings. Existing projects open in Russian.

Use Live to analyze the track input during playback, or drop a file onto the waveform for entire-file analysis. Pitch Shift processes the project track audio; the imported file is used only for analysis. The step is 50 cents (0.5 semitones). The ½ and ×2 buttons adjust detected BPM without changing playback speed.

The installer backs up the previous version under `C:\ProgramData\FLOWMINNERS\FLOWTONE\Backups`. Uninstall using Windows Apps settings. Backups are retained. Windows 10/11 x64 is required. The installer has no publisher certificate.
