# FLOWTONE для Windows

1. Скачайте `FLOWTONE-0.4.0-Windows-x64-Setup.exe` из [релиза](https://github.com/Abynarc/FLOWTONE/releases/tag/v0.4.0).
2. Сохраните проекты и закройте секвенсор.
3. Запустите EXE и выполните установку.
4. В FL Studio: **Manage plugins → Find installed plugins**. Добавьте FLOWTONE как эффект на канал микшера.

Windows 10/11 x64, секвенсор с поддержкой VST3. Папка плагина: `C:\Program Files\Common Files\VST3\FLOWTONE.vst3`.

Выберите **RU** или **EN** справа от «Обход». Язык сохраняется в проекте.

Перетащите аудиофайл на осциллограмму или нажмите «Выбрать файл» для анализа всей записи. «Онлайн» анализирует вход дорожки во время воспроизведения.

Сдвиг высоты обрабатывает звук дорожки, включая экспорт проекта. Загруженный файл используется только для анализа. Кнопки ½ и ×2 изменяют отображаемый BPM, а не скорость аудио. При неоднозначном или переменном темпе отображается соответствующее сообщение.

При обновлении предыдущая версия сохраняется в `C:\ProgramData\FLOWMINNERS\FLOWTONE\Backups`. Удаление через «Установленные приложения» сохраняет резервные копии и пользовательское аудио. Установщик без сертификата издателя.
