FLOWTONE 0.3.1 · FLOWMINNERS · Windows VST3

УСТАНОВКА
1. Сохраните проекты и закройте FL Studio и другие секвенсоры.
2. Запустите FLOWTONE-0.3.1-Windows-x64-Setup.exe.
3. В FL Studio: Options → Manage plugins → Find installed plugins.
   Добавьте FLOWTONE как эффект на нужный канал микшера.
   В другом VST3-секвенсоре обновите список плагинов.

Windows 10 (1607+)/11 x64, 64-разрядный VST3-секвенсор.
Стандартная папка: C:\Program Files\Common Files\VST3\FLOWTONE.vst3
Поддержка конкретной версии секвенсора требует проверки в ней. Это VST3,
не VST2/CLAP/AAX. Плагин не работает в хостах, которые не поддерживают VST3.
Установщик не подписан сертификатом издателя Windows.
Для ручной установки распакуйте VST3 ZIP: всю папку FLOWTONE.vst3 скопируйте
в Common Files\VST3. Внутренний файл отдельно из пакета не извлекайте.

ДВА СПОСОБА АНАЛИЗА
Файл: перенесите один аудиофайл на осциллограмму или нажмите «Выбрать файл».
Вся запись читается в фоне без Play; отображаются прогресс, полная осциллограмма,
BPM и одна тональность на английском. В FL Studio можно использовать ручку
Drag/copy sample/selection редактора Edison. Перенос приватного клипа Playlist
возможен только если FL отдаёт настоящий аудиофайл; общая поддержка виртуальных
FILECONTENTS не реализована. Перенос из Проводника и выбор файла также доступны.
Входящий файл открывается до возврата из Drop, а декодируется в рабочем потоке;
удаление временного файла секвенсором не прерывает чтение из открытого дескриптора.
Не запускайте секвенсор от администратора: Windows ограничивает перенос между
программами с разными уровнями прав.

Онлайн: нажмите «Онлайн» и включите воспроизведение секвенсора. Анализируется
вход нужной дорожки до сдвига высоты; обычно нужен ритмичный фрагмент 12–20 с.
«Файл» возвращает сохранённый результат файла; анализы не смешиваются.
«Повторить анализ» заново читает файл или сбрасывает онлайн-анализ.

ОБРАБОТКА ЗВУКА
Сдвиг от −12 до +12 полутонов, шаг четверть тона = 50 центов = 0,5 полутона.
Сохраняются темп и длительность. Импортированный файл служит только для анализа:
сдвиг обрабатывает вход и выход дорожки, включая экспорт проекта.
Доступны сохранение тембра, стандартное/высокое качество, громкость, пресеты,
A/B, «До / После», обход, ½/×2 BPM. Последние кнопки уточняют трактовку BPM,
не меняя скорость аудио. При дробном сдвиге к тональности добавляются центы.
Задержка обоих качеств одинакова и объявляется хосту для компенсации:
8704 сэмпла при 48 кГц (181,33 мс).

СОХРАНЕНИЕ И ОБНОВЛЕНИЕ
Настройки, A/B, способ анализа, результат и осциллограмма файла сохраняются
в проекте. Аудио в состояние плагина не встраивается. Для повторного чтения
после открытия проекта исходный файл должен оставаться доступным; временный
экспорт секвенсора при необходимости перенесите заново.
AU-экземпляр Logic и VST3-экземпляр Windows — разные форматы. Сам проект Logic
автоматически в FL Studio не переносится.
При обновлении предыдущая системная копия проверяется и сохраняется в
C:\ProgramData\FLOWMINNERS\FLOWTONE\Backups. Удаление через «Установленные
приложения → FLOWTONE VST3» оставляет резервные копии и аудиопроекты.
FLOWALIGN не затрагивается.

ОГРАНИЧЕНИЯ
Моно/стерео, файлы 8–384 кГц, до четырёх часов, обработка блоками без загрузки
всего PCM в RAM. WAV, AIFF, MP3, FLAC, Ogg; дополнительные кодеки зависят от
Windows Media Foundation (в редакциях Windows N может потребоваться Media
Feature Pack). Неоднозначный материал может не дать тональности/BPM.
Стопроцентная точность на любом аудио не обещается. Нет ARA, автоматического
чтения всех регионов, управления Play и самостоятельного проигрывателя файла.

ПРОВЕРКА ПОСЛЕ УСТАНОВКИ
Проверьте оба способа анализа, переключение между ними, сдвиг +12 и ±0,5,
«До / После», экспорт с эффектом, сохранение/открытие проекта. Сравните обычное
и высокое качество. Отдельно проверьте перетаскивание из своего секвенсора.
